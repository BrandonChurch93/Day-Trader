## Fixed handoff

- **Folders:** `/home/user/workspace/rig/data/plan_76/{count,design,heldback}`, with each stage folder owner-only mode 0700 and its inputs regular single-link mode-0600 files owned by the runner. Symlinks are rejected. No production collection, stage start or score is part of this build.
- **Bars:** `bars.f64` is headerless little-endian IEEE binary64, hour-major from start inclusive to stop exclusive, then the full alphabetic roster from config. Each count cell holds just close; design and held-back cells hold open then close. Missing bars are NaNs (both fields together in scored tapes). Opens and closes use the same hourly bucket, labeled by its opening UTC hour; a signal first becomes usable when the bucket has closed. The tape never carries venue flags or data from outside the fence. The runner applies doc 172 trading windows from config, not from the source. Source-specific parsing ends at this normalization boundary.
- **Manifest:** `manifest.json` is UTF-8 JSON with exactly `schema` (integer per config), `stage` (count, design or heldback), `start` and `stop_exclusive` (UTC dates), `names` (all roster names alphabetically), `hours` (integer number of UTC slots), `bars_sha256`, `source_receipt_sha256` and `prior_result_sha256`. Hashes are lowercase full SHA-256. Prior result is null for count; design pins the preceding count result bytes, and held-back pins the preceding design result bytes. The config's tape and metadata length limits are technical fuses, not a permission or a different date fence.
- **Receipts:** `source_receipt.json` records the above rights decision, source/coverage details, byte hashes, pair mappings, gaps, and collection/extraction method. The scorer checks the exact receipt bytes against the manifest; it does not independently determine permission. `receipt.json` is UTF-8 JSON with exactly the schema integer, stage, `manifest_sha256`, and boolean `separate_custodian` and `permission_confirmed`, each true. A real custodian and lead review, not the booleans, establish that separation and permission.
