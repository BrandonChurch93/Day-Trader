Exclude the 12 unresolved funds and one wholly immature fund; no bars, quotes or actions in either stage. Deny overlapping dated ticker or CUSIP usage by any resolved segment based on all approved exclusion records. Provide one proven canonical economic common-class ID for every retained CIK, plus disjoint PCEF, separately from ticker, dated aliases/CUSIPs and identity evidence. Use the same canonical IDs for target closes, placebo legs and all approved successor valuation endpoints. The code enforces injectivity and rejects shared canonical IDs across CIKs, unresolved retained class histories and overlapping known symbols/CUSIPs. Only the 15 lead-approved, dated-primary-ticker segments may lack a cover-page CUSIP; require an exact, separately evidenced exception list. Legitimate noninjective history requires audited remapping, not coercion. A verified identity with no usable endpoint may be evidenced missing, not reclassified as unresolved.
- **Enumerate scope:** For every raw acceptance, mark that subject issue's scheduled entry through entry plus 60 sessions inclusive, even if deduped, skipped or immature. Add independently approved successor valuation days by canonical issue. For each mature candidate at N = 5, 20 and 60, retain only the originally scheduled placebo with no subject interval intersection and no pre-2016 requirement. Derive exact fund and PCEF identity/window keys; do not add alternatives. Full target transport is never a source. The producer may use the strict native Alpaca raw daily bar scanner to return close-token locators and approved volume/date metadata, not decoded bar rows or prices. Independent split-basis diagnostics must be restricted to the approved placebo dates and the PCEF scope exception.
- **Prepare trusted locators:** Build the metadata-only field index from pinned native transport and the permitted physical placebo and PCEF partitions. The volume/date/alias, scope, adjustment and close leaf digest/offset/length must match the [native scanner](placebo_native_63.py) output exactly. The [field projector](placebo_project_63.py) independently opens authorized archives using no-follow scoped file descriptors. It checks compressed and body digests, feed/view from the authenticated transport index, page chains, actual embedded next tokens, dated aliases, return-date bounds, positive volume and false missing markers. It re-scans exact captured bytes without decoding prices and compares every proposed endpoint and its reference before converting any close token. A close token is sliced only from that same verified body at the exact validated offset. Action amounts are taken only from exact jointly attested canonical evidence, not a caller-supplied numeric offset. Custodian and auditor must review the original authenticated HTTP request records behind the compact transport index and the source evidence content before projection.
- **Verify action economics:** Reconcile independent issuer/sponsor evidence, vendor action effective/ex-date, exact cash terms and currency, completeness for both legs and split basis. No amounts from target rows are eligible for processing. Pin a reviewed canonical action receipt per economic event/amount; deduplicate announcements, aliases and vendor IDs. A same-day split precedes cash only on verified then-current entitlement. Only distinct verified same-day cash components on a common basis may be combined into one approved cash amount per day. Fail closed on unexplained split, duplicate action, ambiguous chronology, disagreement, unavailable action coverage or otherwise unmodeled economics. Missing positive-volume bars are separately evidenced missing, never substitutes. A verified absent action set is not an unknown action set.
