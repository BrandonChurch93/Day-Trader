# Perplexity platform options for trading research and paper execution

As of November 24, 2026. The recommended split is a deterministic market-data and paper-order process you operate, an API-based research queue that escalates unusual evidence, and Computer for scheduled briefs, strategy review, and code maintenance. **MEASURED (published):** Claude Fable 5.2 is real, released November 9, and costs $8 per million input tokens and $40 per million output tokens at standard API rates; the name is not a typo ([Anthropic release](https://www.anthropic.com/claude-fable-and-mythos-5-2), [Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing)). Here, MEASURED denotes published rates, official policy text or independent empirical results; STATED means vendor-described functionality not independently tested; UNKNOWN marks unverified guarantees or entitlements. All budget numbers are scenario arithmetic, not observed usage.

## Implications for our build

- **Keep control outside the model:** Let a separately operated process own exchange/broker WebSockets, fresh quotes and timestamps, order IDs, position/exposure and stale-data checks, pre-trade limits, idempotency, reconciliation and the kill switch. Do not place an LLM, browser click, notification, website, or general-purpose workflow in the path for submitting, sizing, cancelling or retrying an order. Start with no live keys and use broker-native paper simulation ([Alpaca paper-trading limitations](https://docs.alpaca.markets/us/docs/paper-trading), [Alpaca streaming](https://docs.alpaca.markets/us/docs/streaming-market-data), [Coinbase WebSocket channels](https://docs.cdp.coinbase.com/coinbase-app/advanced-trade-apis/websocket/websocket-endpoints)).
- **Make escalation research-only:** Use Search/Monitor for sources and Context/Decisions or a cheap model for evidence triage. Send only a deduplicated, timestamped evidence packet to Agent API for harder research, with no trade fields or account credentials. Use one Computer automation on Pro for daily monitoring briefs and weekly review before paying for a Max Teammate. Measure queue age, source freshness, duplicate rate, alert precision/recall and cost per useful alert; no verified return or tail-latency evidence justifies all-Fable polling ([Monitor semantics](https://docs.perplexity.ai/docs/monitors/overview.md), [Computer automation limits](https://www.perplexity.ai/help-center/en/articles/11521526-perplexity-tasks), [API cost reporting](https://docs.perplexity.ai/docs/getting-started/pricing)).
- **Separate research quality from trading edge:** Log first-known timestamps, use point-in-time constituents including delistings, lock out-of-sample windows and track every variant tried. Model spreads, fees, queue priority, partial fills, slippage and latency; run shadow/paper against a deterministic baseline before considering capital. Public sources, clean-looking dashboards and paper fills do not establish that the agent adds net returns ([Bailey et al. on probability of backtest overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf), [Portfolio Backtesting: seven sins](https://portfoliooptimizationbook.com/slides/slides-backtesting.pdf), [Alpaca paper execution limitations](https://docs.alpaca.markets/us/docs/paper-trading)).
