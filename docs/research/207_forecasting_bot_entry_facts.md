# FutureEval bot entry facts

Queue 147, checked November 27, 2026, Mountain Time. Documentation only: no account, endpoint calls, question records or submissions. This is an autonomous contest test, not a forecast of steady income.

- MEASURED, current season: The Fall 2026 FutureEval Bot Tournament is live. Metaculus advertises a September 28, 2026 start, a January 6, 2027 forecasting close and a $50,000 main pool. Page metadata puts the forecasting cutoff at January 5, 2027, 5 PM Mountain Time, and lists March 4, 2027, 5 PM Mountain Time as the separate administrative close. Neither is a promise that new questions will still be opening then. The $58,000 shown on the FutureEval hub is the broader seasonal program, including separate $1,000 MiniBench rounds, not the main contest's pool ([Fall tournament page and metadata](https://www.metaculus.com/tournament/fall-futureeval-2026/?tab=about), [Fall launch notice](https://www.metaculus.com/notebooks/45615/announcement-of-futureeval-fall-2026/), [FutureEval hub](https://www.metaculus.com/futureeval/), [bot resources](https://www.metaculus.com/notebooks/38928/bot-tournament-resources-page/)).
- MEASURED, late entry: “Competitors can join any time during this window and will start in the middle of the leaderboard with 0 points.” The notice says new questions stop opening a few weeks before January 1, not that entry remains useful until the January forecasting cutoff. Spot peer score uses the last forecast before each close; the scoring FAQ says “you get 0 for any question you didn't forecast.” INFERENCE: No separate late penalty and no backfill: previously closed questions are lost chances to earn points. UNKNOWN exact last opening date. Plan for 300 to 400 questions for the full season, with 206 shown on the page checked, not 206 still available. “Questions from either series launch at random hours and will be open for 3 hours each.” Several may open together, usually five or fewer. There is no fixed daily release hour ([Fall launch notice](https://www.metaculus.com/notebooks/45615/announcement-of-futureeval-fall-2026/), [Fall tournament page](https://www.metaculus.com/tournament/fall-futureeval-2026/?tab=about), [bot resources](https://www.metaculus.com/notebooks/38928/bot-tournament-resources-page/), [scoring FAQ](https://www.metaculus.com/help/scores-faq/#tournament-scores)).
- MEASURED, owner setup in order: (1) Use the owner's human account, or sign up personally if he does not have one. “A human should create the human account.” (2) In [My Forecasting Bots settings](https://www.metaculus.com/accounts/settings/bots/), click Create Bot, enter its details and copy the bot API key. The first is primary; extras are secondary and not prize-eligible. (3) Register the bot via the [Fall tournament landing page](https://www.metaculus.com/tournament/fall-futureeval-2026/?tab=about) and accept its terms: entrants “must create a free Metaculus bot account, if they do not already have one, and register for the Tournament via the Tournament landing page.” (4) Before the first submission, complete the first section of the [participation form](https://forms.gle/aQdYMq9Pisrf1v7d8), three required questions. Confirm eligibility and any collaborator permissions. No identity upload or tax form is listed at entry; “Prize recipients will be required to verify their identity, nationality, and residency.” Later, complete the end-of-season survey and any verification, W-9 and bank details directly with Metaculus/Ramp, not with the build team ([setup and payment resources](https://www.metaculus.com/notebooks/38928/bot-tournament-resources-page/), [FutureEval rules](https://www.metaculus.com/notebooks/28751/q4-ai-forecasting-benchmark-rules/), [Fall participation requirements](https://www.metaculus.com/notebooks/45615/announcement-of-futureeval-fall-2026/), [general prize rules](https://www.metaculus.com/tournament-rules/)).
- INFERENCE, secret handoff: If authorized, the owner enters only the bot token as `METACULUS_TOKEN` in the approved runner's secret store, not in chat, a prompt, a ticket, a tracked or colocated file, or a command-line argument. Keep the human password, email access, recovery codes, ID, tax and bank details private. Give only the submission process access at runtime; keep secrets out of model context and tool outputs, redact authorization headers and environment dumps, disable verbose request tracing, and revoke/rotate immediately on exposure. With GitHub Actions, use an owner-controlled Actions secret and trusted workflows only; never print it or expose it to pull request code. No token needed for preparation ([template secret setup](https://github.com/Metaculus/metac-bot-template), [FutureEval account rules](https://www.metaculus.com/notebooks/28751/q4-ai-forecasting-benchmark-rules/)).
- MEASURED, template and scheduling: [Metaculus's Python template](https://github.com/Metaculus/metac-bot-template) documents `uv`, `METACULUS_TOKEN` and at least one LLM key, with OpenRouter recommended and alternatives supported. The [template environment file](https://github.com/Metaculus/metac-bot-template/blob/main/.env.template) calls search providers “all optional” and says it falls back to LLM-only research. GitHub Actions is a suggested 20-minute schedule, not a rule: the README documents local runs and the organizer says “You do not need to use the template bot.” INFERENCE: Our own persistent scheduler is fine; poll with margin inside three hours, guard against duplicate submissions and explicitly select the approved project. The stock tournament mode sends to both main FutureEval and MiniBench. UNKNOWN template license: no license file or license declaration found in the current template root or package metadata; the organizer calls it open source in its resource list but that is not a license grant. Do not copy or ship the template code without clarification; an independent implementation can use official documentation ([template README](https://github.com/Metaculus/metac-bot-template), [package metadata](https://github.com/Metaculus/metac-bot-template/blob/main/pyproject.toml), [template source](https://github.com/Metaculus/metac-bot-template/blob/main/main.py), [bot resources](https://www.metaculus.com/notebooks/38928/bot-tournament-resources-page/)).
- MEASURED, credits: “AskNews search is free for every registered bot maker, and we also give donated LLM credits to a select number of bot makers who apply.” Apply for OpenAI, Anthropic or Google credits via OpenRouter in the participation form; do not assume an award. To claim AskNews, sign up with the same email as the Metaculus bot, request activation through the resource page's Discord contact or [AskNews support](mailto:contact@asknews.app), generate the key after approval and renew each season. Posted limits: 1,000 calls/month and 4,000 per tournament; archive queries cost five calls. Keep separate provider keys in the runner's secret store ([credit and AskNews steps](https://www.metaculus.com/notebooks/38928/bot-tournament-resources-page/), [Fall credit notice](https://www.metaculus.com/notebooks/45615/announcement-of-futureeval-fall-2026/)).
- MEASURED, submissions and disqualification: “Your bot must autonomously generate forecasts to questions included in the Tournament as well as written comments accompanying each forecast.” Include the probability or distribution and the rationale in each private comment; these can later become public. “Bots may not have a human in the loop when forecasting.” That includes looking at an open/upcoming question's outputs and editing the bot in response. No blind copying of crowd predictions, even via an LLM. One prize bot per person/team; unmarked duplicates, multiple identities and sharing accounts violate the rules. Missing comments, declining code inspection or a demo, or failing prize verification can cost eligibility; missed surveys can cause removal. Fall excludes closed-source commercial bots from prizes; fully opening commercial bot code by season end is the exception. If using employer resources or operating for a company, verify classification before entry ([FutureEval rules](https://www.metaculus.com/notebooks/28751/q4-ai-forecasting-benchmark-rules/), [comment requirements](https://www.metaculus.com/notebooks/38928/bot-tournament-resources-page/), [Fall policies](https://www.metaculus.com/notebooks/45615/announcement-of-futureeval-fall-2026/)).
