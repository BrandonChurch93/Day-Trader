## 1. Statistics Derivation and Made-Up-Data Tests

### Line-by-line check against original papers

1. **Deflated Sharpe Ratio (`engine.py:45-52`)** — Bailey & Lopez de Prado (2014), JPM 40(5), Eqs. (2), (6), (8):
   - Formula in paper:
     \[
     \widehat{SR}_0 = \sqrt{V[\{\widehat{SR}_n\}]} \left((1 - \gamma) Z^{-1}\!\left(1 - \frac{1}{N}\right) + \gamma Z^{-1}\!\left(1 - \frac{1}{Ne}\right)\right)
     \]
     \[
     \widehat{DSR} = Z\!\left(\frac{(\widehat{SR} - \widehat{SR}_0)\sqrt{T-1}}{\sqrt{1 - \hat{\gamma}_3 \widehat{SR} + \frac{\hat{\gamma}_4 - 1}{4}\widehat{SR}^2}}\right)
     \]
   - `engine.py` uses per-period Sharpe (`sharpe_per_period`, `ddof=1`), `stats.skew(r)` (\(\hat{\gamma}_3\)), raw kurtosis `stats.kurtosis(r, fisher=False)` (\(\hat{\gamma}_4\), normal = 3), Euler-Mascheroni constant `0.5772156649`, and `\sqrt{T-1}` with `max(1e-12, ...)` under the square root. The algebra matches the paper.
   - Issues noted in F7: no guard for `n_trials <= 1`; empirical cross-sectional std `sr_trials_std` shrinks under high cross-rule correlation (raising false positives) and expands when one strong rule is pooled with noise rules (lowering power).

2. **CSCV PBO (`engine.py:54-64`)** — Bailey, Borwein, Lopez de Prado & Zhu (2017), JCF:
   - Splits `T` periods into `S` equal blocks, iterates all \(\binom{S}{S/2}\) IS/OOS halves, picks `best = argmax(IS Sharpe)`, computes OOS relative rank `w = rank / (N + 1)` and logit `lam = log(w / (1 - w))`.
   - Two issues found:
     - **F1 (changes results)**: Line 64 uses `(lam <= 0).mean()`. For odd `N = 9`, exact median rank 5 yields `w = 0.5, lam = 0.0`, which is counted as overfit, giving null expectation `5/9 = 0.556` instead of `0.500`. On `X2 BTCUSD Binance.US`, 8.00% of splits hit `lam == 0`, pushing PBO from `0.1701` (`lam < 0`) or `0.2101` (tie-split) to `0.25012` (`lam <= 0`), failing `< 0.25` by `0.00012` and flipping 4 rule verdicts.
     - **F4 (could change results)**: Line 62 has no zero-std guard before dividing `mean / std`.

3. **Block Bootstrap of Sharpe Difference (`engine.py:66-72`)**:
   - Draws `ceil(n / block)` contiguous blocks of length `block` uniformly from `0..n-block`, concatenates and truncates to `n`, pairs the same indices `idx` for `ra` and `rb` (preserving cross-sectional correlation), and returns `[5, 50, 95]` percentiles of annualized Sharpe difference.
   - Standard non-circular moving block bootstrap (minor boundary downweighting of the first/last 29 days out of 3,186-5,075 days). Correctly returns `[0, 0, 0]` when `ra == rb` and brackets the sample Sharpe difference accurately.

4. **Shuffled Timing (`engine.py:74-80`, `common_03.py:32-34`)**:
   - Breaks `target` wherever `t[i] != t[s]` and permutes all chunks together.
   - **F2 (could change results)**: Breaks `P2` into ~3,347 mostly 1-day spells (3.1x trades, 5.2x turnover in shuffles) and halves trade count on binary rules by merging adjacent identical spells.
